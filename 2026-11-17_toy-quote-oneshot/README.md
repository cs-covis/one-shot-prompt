# 가벼운 AI 셋에게 같은 프롬프트 하나로 시킨 견적서·거래명세서 프로그램 (토이 프로젝트 원샷 비교)

킴영감의 AI 코딩팁! 쇼츠에서 같은 프롬프트 한 번으로 만들어 본 결과물입니다.

## 프롬프트

```
보는 사람이 "이걸 AI가 한 번에 만들었다고?" 하고 감탄할 만큼 아름다운 견적서·거래명세서 프로그램을 만들어 줘. 기능은 작은 회사가 매일 쓰는 실무 도구 그대로이고, 겉모습은 디자인 잡지에 실릴 만한 고급 문구점 같은 작업대여야 해. 브라우저에서 index.html 파일 하나만 열면 바로 쓸 수 있어야 하고, 설치·서버·로그인은 없어야 해(글꼴 같은 외부 자료는 CDN으로 불러와도 된다).

[분위기와 화면]
- 바탕은 깊은 남색 작업대. 그 위에 크림빛이 살짝 도는 흰 A4 세로 종이 한 장이 부드러운 그림자와 함께 떠 있다. 종이에는 아주 옅은 종이 결이 보인다.
- 글꼴은 Pretendard(제목은 굵게, 숫자는 고정폭 숫자). 강조색은 딥 그린 하나만 쓰고, 도장만 빨간색이다. 기본 브라우저 버튼·표·입력 칸 모양이 그대로 남은 곳이 한 군데도 없어야 한다.
- 종이 맨 위에 자간을 넓힌 큰 제목 '견 적 서'와 얇은 이중선. 그 아래 왼쪽에 받는 곳(회사명 크게, 담당자 '귀하'), 오른쪽에 공급자 표(상호, 대표자, 사업자등록번호, 주소, 전화).
- 공급자 상호 옆에는 상호 글자로 자동으로 만든 빨간 원형 도장(SVG, 테두리가 살짝 거칠고 약간 기울어진 진짜 도장 느낌)이 찍혀 있다. 상호를 고치면 도장 글자도 바뀐다.
- 견적일은 오늘 날짜, 견적번호는 날짜와 그날의 순번(예: Q-20261117-01, 다음은 Q-20261117-02). 유효기간 기본값은 견적일로부터 30일.
- 품목 표의 열은 순서대로 번호 · 품목명 · 규격 · 수량 · 단가 · 금액 · 비고. 금액은 수량×단가로 자동 계산되고 고칠 수 없다. 줄에 마우스를 올리면 끝에 지우기 ✕가 나타난다. 입력 칸은 평소엔 인쇄된 글자처럼 보이고, 누르면 딥 그린 밑줄이 생긴다.
- 품목 표 위에는 합계를 한글로 크게 '일금 ○○○원정 (₩000,000)'으로, 표 아래에는 공급가액 · 부가세(10%) · 합계를 오른쪽 정렬로 보인다. 합계 줄은 딥 그린 띠 위에 흰 글자.
- 종이 위쪽 떠 있는 둥근 도구 막대에 아이콘이 붙은 버튼 다섯 개: '품목 추가', '거래명세서로 보기', '저장', '새 견적서', '인쇄'.
- 종이 오른쪽에는 '저장한 견적' 카드들이 쌓인다(견적번호 · 받는 곳 · 합계 · 날짜). 카드를 누르면 그 견적이 다시 열린다. 저장할 때 카드가 위에서 내려앉고, 화면 아래에 '저장했어요' 알림이 잠깐 떴다 사라진다.
- 휴대폰처럼 좁은 세로 화면에서도 종이 전체가 화면 폭에 맞게 줄어들어 한눈에 보이고, 카드 목록은 종이 아래로 내려간다.

[움직임 — 이 프로그램의 볼거리]
- 엑셀이나 구글 시트에서 '품목명, 규격, 수량, 단가' 순서의 여러 줄을 복사해 품목 표의 아무 칸을 누르고 Ctrl+V 하면, 붙여넣은 줄 수만큼 새 품목 줄이 표 끝에 하나씩 차례로(줄마다 0.1초 간격) 아래에서 미끄러져 들어오고, 새로 채워진 금액 칸이 잠깐 연한 금빛으로 반짝인다.
- 공급가액·부가세·합계 숫자는 바뀔 때 이전 값에서 새 값까지 0.7초 동안 굴러가듯 올라간다. 한글 금액은 새 문장으로 부드럽게 바뀐다.
- '거래명세서로 보기'를 누르면 종이가 카드처럼 3D로 뒤집히며 반대 면에 거래명세서가 나온다: 제목 '거 래 명 세 서', 받는 곳은 '공급받는자', 견적일 자리는 '거래일자', 유효기간은 숨긴다. 품목과 금액은 그대로다. 버튼 글자는 '견적서로 보기'로 바뀌고, 다시 누르면 반대로 뒤집힌다.
- 품목이 하나도 없을 때는 표 자리에 점선 상자와 작은 표 그림, '엑셀에서 복사해 여기에 붙여넣으세요 (Ctrl+V)' 안내가 보인다.
- 움직임은 모두 부드럽고 짧게(과하게 튀지 않게). 사용자가 '동작 줄이기'를 켜 두었으면 움직임 없이 바로 바뀐다.

[엑셀 붙여넣기 규칙]
- 칸 하나에 글자가 몰려 들어가면 안 된다. 복사한 숫자에 붙은 쉼표·'원'·공백은 지우고 읽는다(예: '24,900원' → 24900). 빈 줄은 건너뛴다. 칸이 하나뿐인 글자를 붙여넣을 때는 보통 붙여넣기처럼 그 칸에만 들어간다.

[계산 규칙 — 틀리면 안 되는 부분]
- 모든 금액(단가 포함)은 원 단위이고 천 단위마다 쉼표를 찍는다(1,234,500).
- 부가세는 공급가액 합계의 10%에서 원 미만을 버린다. 합계 = 공급가액 + 부가세.
- 한글 금액은 숫자 그대로 읽어 만들고, 십·백·천 앞의 '일'도 빼지 않는다. 예: 1,110원 → 일금 일천일백일십원정 / 20,005원 → 일금 이만오원정 / 3,000,000원 → 일금 삼백만원정 / 0원 → 일금 영원정.
- 수량·단가에 숫자가 아닌 것이 들어오면 0으로 보고, 음수는 받지 않는다.

[저장과 새 견적서]
- 고친 내용은 브라우저에 자동으로 저장돼서, 창을 닫았다 열어도 그대로 남는다.
- '저장'을 누르면 지금 견적이 '저장한 견적'에 들어간다(같은 번호면 덮어쓴다). '새 견적서'는 지금 견적을 저장한 뒤, 품목이 빈 새 견적서를 다음 번호로 연다(받는 곳은 비우고 공급자 정보와 도장은 그대로 둔다). 확인 창은 띄우지 않는다.

[처음 열었을 때]
- 받는 곳 '샘플상사 김민수', 공급자 상호 '예시오피스'(나머지 공급자 칸은 비워 둔다)와 품목 세 줄이 미리 채워져 있어서 열자마자 완성된 견적서가 보인다.
  노트북 거치대 / 알루미늄 / 3 / 45,000
  무선 키보드 / 한글 각인 / 5 / 32,900
  설치 출장비 / 서울 / 1 / 150,000

[인쇄]
- '인쇄'를 누르면 작업대·도구 막대·카드·그림자·움직임이 모두 사라지고, 지금 보이는 문서(견적서 또는 거래명세서)만 도장과 함께 A4 세로 한 장에 여백을 맞춰 인쇄된다(PDF로 저장해도 같다).

[끝내기 전에 스스로 확인할 것]
- 예시 세 줄의 공급가액 449,500 · 부가세 44,950 · 합계 494,450 · '일금 사십구만사천사백오십원정'이 맞는지 직접 계산해 봐.
- 탭으로 칸을, 줄바꿈으로 줄을 나눈 글자를 실제로 붙여넣어 봐서 줄과 칸이 제대로 나뉘고 움직임이 자연스러운지 확인해.
- 화면을 처음 보는 사람의 눈으로 다시 훑어보고, 기본 HTML 처럼 보이는 곳·어긋난 정렬·어색한 여백이 남아 있으면 다듬어.
- 저장 → 새 견적서 → 카드로 앞 견적 다시 열기가 끊김 없이 되는지, 품목을 열 줄까지 늘려도 인쇄가 한 장에 들어가는지 확인해.

질문하지 말고 끝까지 완성해.
```

## 이 비교에서 알아 둘 것

- **모델과 추론 강도**: Claude Haiku 5.5(Claude Code, medium), GPT-6 Luna(Codex CLI, medium), Gemini 4 Hydrogen(Antigravity CLI, Medium 모델). 세 모델 모두 회사마다 내놓은 모델 가운데 가벼운 쪽입니다. 공식 API 가격표로 Haiku 5.5와 GPT-6 Luna는 입력 $0.10·출력 $0.50(기본 구간), Gemini 4 Hydrogen은 $1.50/$7.50입니다. 이번 실행은 각 도구의 로그인·구독 사용량이라 이 금액을 낸 것은 아닙니다.
- **도구 버전**: Claude Code 2.1.326, Codex CLI 0.169.0, Antigravity CLI 1.5.10 (2026-11-18 기준).
- **권한**: 같은 권한이 아니라, 일하는 데 막히지 않도록 도구마다 제 방식으로 작업 폴더 안 파일 쓰기·명령 실행을 허용했습니다(Claude Code acceptEdits와 허용 도구 목록, Codex workspace-write와 네트워크 허용, Antigravity accept-edits).
- **시도 횟수**: 세 모델 모두 이 프롬프트로 한 번씩 시켰고 첫 시도 결과입니다.
- **앞선 두 번의 시도**: 같은 견적서 과제를 화면 묘사가 적은 프롬프트로 먼저 두 번 돌렸습니다(첫 번째는 견적서만, 두 번째는 엑셀 붙여넣기·거래명세서·저장 목록을 더함). 두 번 모두 셋 다 그때 정한 기능은 통과했지만 화면이 평범한 표였습니다. 이 폴더의 프롬프트는 화면과 움직임을 구체적으로 적은 세 번째 프롬프트입니다.

## 완성 기준 5개와 확인 결과 (브라우저로 열어 정해 둔 조작을 하고 스크린샷·인쇄 PDF로 확인)

기준: ① 오류 없이 작업대 위 A4 견적서·예시 세 줄·버튼 다섯 개·빨간 원형 도장이 보인다 ② 엑셀 형식 세 줄(쉼표·'원'·빈 줄 포함)을 붙여넣으면 줄이 칸에 맞게 들어오고 공급가액 876,499 · 부가세 87,649 · 합계 964,148 · '일금 구십육만사천일백사십팔원정'이 된다 ③ '거래명세서로 보기'를 누르면 종이가 뒤집히며 거래명세서가 되고 합계는 그대로다 ④ 저장 → 새 견적서(-02) → 카드로 다시 열기, 새로고침 뒤에도 남는다 ⑤ A4 인쇄가 한 장이고 버튼·카드가 인쇄되지 않으며, 세로 화면에서 종이가 폭 안에 들어온다

| 조합 | ① | ② | ③ | ④ | ⑤ |
|---|---|---|---|---|---|
| Claude Haiku 5.5 | ○ | ○ | ○ | ○ | ○ |
| GPT-6 Luna | ○ | ○ (거래명세서 면의 단가는 쉼표 없이 보임) | ○ | ○ | ○ |
| Gemini 4 Hydrogen | ○ | ○ | ○ | ○ | ○ |

붙여넣기 값(세 줄과 빈 줄)은 프롬프트에 없는 확인용 값입니다. 엑셀 앱에서 직접 복사하지 않고, 엑셀이 클립보드에 넣는 것과 같은 탭·줄바꿈 글자를 넣어 실제 Ctrl+V로 확인했습니다. 이 표는 이 과제를 한 번 시킨 결과일 뿐 모델의 일반적인 우열이 아닙니다.
