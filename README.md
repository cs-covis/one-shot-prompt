# One-Shot Prompt

**같은 프롬프트 한 번으로 여러 AI에게 만들게 한 결과물과 그 프롬프트 전문을 모아 두는 저장소입니다.**

## 채널 — 킴영감 코딩 캠프

[![YouTube](https://img.shields.io/badge/YouTube-%40elderlykim-red?logo=youtube)](https://www.youtube.com/@elderlykim)

킴영감 코딩 캠프는 AI를 활용한 바이브코딩과 업무 자동화를 다루는 유튜브 채널입니다. 코딩을 몰라도 AI 코딩 도구로 바로 써먹는 방법을 입문자부터 개발자까지 따라 할 수 있게 보여 드립니다.

이 저장소에는 채널의 **「킴영감의 AI 코딩팁!」** 영상(쇼츠·롱폼) 가운데, AI 코딩 도구에 같은 프롬프트를 한 번만 넣고(원샷) 결과를 나란히 비교한 편의 자료를 올립니다.

## 폴더 구성

편마다 `<날짜>_<주제>` 이름의 폴더가 하나씩 있습니다.

| 들어 있는 것 | 설명 |
|---|---|
| `README.md` | 프롬프트 전문(복사해서 바로 쓸 수 있습니다), 모델별 설정·걸린 시간·비용, 결과 설명, 영상 링크 |
| `<모델명>/` | 그 모델이 만든 결과물(영상에 나온 것). `index.html` 이 있으면 아래 주소로 바로 열어 볼 수 있습니다 |

결과물 열어 보기: `https://cs-covis.github.io/one-shot-prompt/<편 폴더>/<모델명>/`

## 이용 안내

- 프롬프트는 자유롭게 복사해 써 보셔도 됩니다. 같은 프롬프트라도 모델·버전·실행 시점에 따라 결과가 달라질 수 있습니다.
- 각 편의 기준일과 실행 조건은 그 편 폴더의 `README.md` 에 적어 두었습니다.
